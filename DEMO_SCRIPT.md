# Two-minute OutsideFix demo

1. **Opening (15 seconds):** “OutsideFix turns an outdoor observation into a practical action. The goal is to get people off the screen and into the world.”
2. **Photo input (20 seconds):** Upload a real photo of a safe, permitted outdoor situation. Briefly explain any context added.
3. **Gemma result (30 seconds):** Show the generated observation, action, duration, materials, steps, and safety notes. State that the response came from the configured Gemma endpoint only if verified.
4. **Action (20 seconds):** Explain the real-world action you completed. Do not claim a task happened if it did not.
5. **Evidence and history (20 seconds):** Show the after-photo/reflection and saved mission. Explain that completion is user-reported.
6. **Open innovation (15 seconds):** Explain why Gemma is central and show the actual configured architecture.
7. **Close (10 seconds):** “A useful AI experience should make the real-world action easier—not keep you in the app.”

Use only real screenshots and a real working deployment.
